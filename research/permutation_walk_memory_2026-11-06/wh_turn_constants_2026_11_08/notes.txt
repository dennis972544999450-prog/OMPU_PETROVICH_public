1. ОБОЗНАЧЕНИЯ (как в §6.4)
Y — шаг с плотностью k(y) = (1−|y|)₊, σ² = 1/6. L = L_same: (Lf)(x) = ∫_0^∞ k(x−y) f(y) dy, x ≥ 0.
V — гармоническая функция убитого блуждания с наклоном 1: V = LV на [0,∞), V(x) = x + δ₀ + o(1).
T — поворот: (Tf)(u) = ∫_0^{1−u} (1−u−t) f(t) dt на [0,1].
H — лестничная высота (первый выход в (0,∞) из 0; по симметрии та же, что модуль нисходящей).
P(s) := 1 − E e^{−sH} (целая), Q(s) := 1 − E e^{−sY} = 1 − 4 sh²(s/2)/s².
U — функция восстановления H (U(0)=1). V = E[H]·U, E[H] = 1/√12 (Спитцер, §6.4).
Нормировка §6.1 ⟨V,1−x⟩ = 1 даёт V_§6.1 = U = √12·V (следует из теоремы A при m = −1).

2. ТЕОРЕМА A (поворот гармонической функции = хвост лестничной высоты)
    (TV)(u) = E[H] · P(H > u),   u ∈ [0,1].
Доказательство. Продолжим V нулём на (−∞,0): V₊. Тогда k∗V₊ = V₊ + W₋, где W₋ сосредоточена
на [−1,0) и W₋(−u) = ∫_0^{1−u}(1−u−y)V(y)dy = (TV)(u). Двусторонний Лаплас при малом Re s > 0:
E e^{−sY}·F(s) = F(s) + ∫_0^1 e^{su}(TV)(u)du, F(s) = ∫_0^∞ e^{−sx}V(x)dx = E[H]/(s P(s)).
Факторизация Винера–Хопфа Q(s) = P(s)P(−s) (симметричный непрерывный шаг: восходящая и
нисходящая высоты равны по закону) даёт ∫_0^1 e^{su}(TV)(u)du = −Q F = −E[H] P(−s)/s
= E[H] (E e^{sH} − 1)/s = E[H] ∫_0^1 e^{su} P(H>u) du. Единственность обращения Лапласа. ∎
Проверки концов: u=0 — гармоничность в нуле (TV)(0) = V(0) = E[H] (так и в §6.4); u=1 — 0.
Следствия (моменты): ∫_0^1 u^m (TV)(u) du = E[H]E[H^{m+1}]/(m+1), то есть
    ⟨V, (1−t)^{m+2}⟩ = (m+2) E[H] E[H^{m+1}],  m ≥ −1.
m=0: ∫TV = 1/12; m=1: ∫u·TV = δ₀/12. Сетка: 0.083333333333 и 0.018945898341 = δ₀/12 (grid_check.out).

3b. ПОКАЗАТЕЛЬ e^{−s/2} — набросок (добавлено 17:1x, после старта рецензии — ею НЕ покрыто)
Π(s) := E[H]·s·Π_k(1 − s/s_k) (пары сопряжённых вместе). Адамар для Q (чётная, порядок 1) даёт
Π(s)Π(−s) = Q(s) = P(s)P(−s), нули P — ровно левые нули Q (в Re s>0 |E e^{−sH}|<1, на мнимой оси
только s=0). Отсюда E(s) := P(s)/Π(s) целая без нулей, E(s)E(−s) = 1, порядок ≤ 1 ⇒ E(s) = e^{βs}.
β: при s → +∞ P → 1, а log Π(s) = log(E[H]s) + Σ_k log|1 − s/s_k|²/2 по парам; при s_k = −a_k ± ib_k,
b_k ≈ 2π(k+½), a_k ≈ 2 log(2π(k+½)): Σ log(1 + s²/b_k²) = log ch(s/2) + o(1) = s/2 + O(1), поправка от a_k —
Σ log(1 + 2s a_k/(b_k²+s²)) = O(log² s). Значит β = −1/2. Не выписано: равномерные оценки остатков
асимптотики корней (стандартны для sin w = ±w).

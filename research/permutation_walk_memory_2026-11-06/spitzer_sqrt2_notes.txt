1. Оператор — простое убитое блуждание
   step_same в модуле Дена Б кладёт на соседние ячейки j±1 двойные интегралы I² и R I² R, а на
   ячейку j — c_0 − (I² + RI²R). Это ровно Теорема 2 статьи: (f_j^new)'' = f_{j−1} − 2 f_j + f_{j+1},
   то есть вторая производная свёртки с ядром (1 − |z|)_+ (у ядра K'' = δ_{−1} − 2δ_0 + δ_{+1}).
   Ячейка j = −1 не создаётся → масса, ушедшая ниже нуля, гибнет. Отождествление Antigravity
   подтверждаю: L_same на x = j + u ≥ 0 есть оператор Винера–Хопфа (Kf)(x) = ∫_0^∞ (1−|x−y|)_+ f(y) dy,
   шаг = U + U' с U, U' ~ U[−½, ½], σ² = ∫ z²(1−|z|) dz = 1/6.

2. Классика, которой это измеряется
   (а) Гармоническая функция убитого блуждания с наклоном 1: V(x) = x + E_x[−S_τ], τ = первый n с S_n < 0.
       Гармоничность: E_x[V(S_1); S_1 ≥ 0] − V(x) = E_x[S_1] − x = 0 (нулевое среднее шага). При x → ∞
       V(x) = x + δ_0 + o(1), δ_0 = lim E_x[−S_τ] (стационарный недолёт). V(0) = E[−S_τ | S_0 = 0] =
       среднее первой (строгой) нисходящей лестничной высоты = E[H] по симметрии.
   (б) Спитцер для симметричного непрерывного шага: 1 − φ(ξ) = (1 − χ₊(ξ))(1 − χ₋(ξ)), χ₋(ξ) = χ₊(−ξ) =
       conj χ₊(ξ), откуда 1 − φ(ξ) = |1 − χ₊(ξ)|². При ξ → 0: σ²ξ²/2 = ξ² E[H]² ⇒ E[H] = σ/√2.
       Для треугольного ядра: V(0) = E[H] = (1/√6)/√2 = 1/√12 = 0.288675134…, НЕ 1/√6 = 0.408248290….
   (в) Локальная теорема для убитого блуждания: P_x(S_n ∈ dy, τ > n) ~ C · V(x) V(y) n^{−3/2} dy при
       фиксированных x, y; сшивка с хвостом P_x(τ > n) ~ √(2/π) V(x)/(σ√n) и рэлеевским пределом
       S_n/(σ√n) даёт C = √(2/π)/σ³ (здесь 12√3/√π = 11.72646). Отсюда предельное ядро в нуле:
       K_∞(0,0) = C V(0)² = √(2/π)/σ³ · σ²/2 = 1/(σ√(2π)) = √(3/π) = 0.977205024…
       Литературные указатели (Vatutin–Wachtel 2009, Doney 2012, Denisov–Wachtel 2015) — см. §5.

4. Вывод
   V_1 письма и статьи = √2 · V. Нормировка V_1 в коде задана не наклоном на бесконечности (его на [0,1]
   при D=12 не видно, и проверки нет), а строкой v1_orth = eigvec · √(λ/A) с A = 6√(3/π) = C/2.
   Поэтому в §6.4 п.1 и §8:
   (i)  «V_1(x) ~ x + δ_0» неверно: V_1(x) ~ √2·x + const.
   (ii) «V_1(0) = σ по точному граничному тождеству Спитцера» — не теорема Спитцера. Спитцер даёт
        V(0) = σ/√2 для функции с наклоном 1. Равенство V_1(0) = σ верно, но как следствие выбранной
        нормировки A: A·V_1(0)² = C·V(0)² = 1/(σ√(2π)).
   (iii) Всё ниже по тексту инвариантно к этому множителю, потому что входит только A·|V_1⟩⟨V_1| = C·|V⟩⟨V|:
        c_1 = A⟨V_1, TV_1⟩, c_2, C_ρ = 5.5589673, ранг 1, пропуск r^{−5/2}. Числа не меняются.
   (iv) В «бакете теорем» §6.4 п.4 и §8 пункт «classical Spitzer V_1(0) = σ = 1/√6» — ровно тот, за
        который рука поручилась (Φ 13:12). Верная формулировка: «для V с наклоном 1 V(0) = σ/√2 = 1/√12
        (Спитцер); предельное ядро в нуле K_∞(0,0) = 1/(σ√(2π)) = √(3/π) (локальная теорема); V_1 = √2 V».

9. Литература (агент с поиском, 13:37–13:51; читал ar5iv/arXiv-HTML, PDF AMS 403, Feller не в открытом доступе)
   - E[H] = σ/√2 для симметричного непрерывного шага: Godrèche & Luck, «On the first positive position of a
     random walker», arXiv:2501.17268 (J. Stat. Phys. 192:105, 2025): 2D = ⟨η²⟩, ⟨H⟩ = √D (eq. 1.14, 2.58, 4.9),
     «known for long», со ссылкой на Spitzer (1960) и Feller (1971). Гауссов случай: Mendonça arXiv:2605.29185,
     Appendix A, E₀(X_{τ+}) = 1/√2 при σ = 1 (по Chang & Peres, Ann. Probab. 25, 1997). Решётчатый аналог:
     Uchiyama arXiv:1805.03971, Theorem A(i).
   - Хвост с явной константой и нормировкой наклона 1: Denisov, Sakhanenko & Wachtel, arXiv:1611.00493, §1.1,
     display (3): P(τ_x > n) ~ √(2/π)·E[−S_{τ_x}]/√n при E X² = 1 (⇒ √(2/π)V(x)/(σ√n), V(x) = E[−S_{τ_x}] = x + …).
   - Локальная теорема: Denisov & Wachtel, «Random walks in cones», arXiv:1110.1254 (Ann. Probab. 43, 2015),
     Theorem 6 (решётка): P(x+S(n) = y, τ_x > n) ~ ϱ H₀² V(x)V′(y)/n^{p+d/2}, ϱ = ϰ²∫_K u²e^{−|w|²/2}dw; для d = 1,
     p = 1: ϰ = √(2/π) (броуновское), H₀ = 1, ϱ = √(2/π) — числа не выписаны в источнике, подставлены нами;
     нормировка V(x) = x − E[x + S(τ_x)] ~ x (§2.4). Непрерывный случай у Doney arXiv:1006.5316 (Prop. 12) и
     Vatutin–Wachtel arXiv:0711.1302 (Thm 3) — в терминах функций обновления, без σ.
   - Тот же компромисс √2 в литературе: Denisov, Tarasov & Wachtel arXiv:2401.09929, eq. (1):
     P(τ_x > n) ~ V₁(x)/√(πn), т.е. их V₁ = √2·V/σ относительно наклона 1.
   Итог для бакета: E[H] = σ/√2 — цитируемая классика; константа C — классическая теорема с константой,
